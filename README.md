# 圣诞星愿 · 极光魔法流畅版

一棵会回应手势的 WebGL 圣诞树：两万多颗星尘粒子、极光与降雪、银蓝色的「呼神护卫」光鹿，
以及用摄像头识别 **张手 / 握拳 / 捏合** 的手势交互。全部在浏览器本机运行，
照片与摄像头画面不会上传、不会录制，也无需联网即可体验。

## 在线体验

- **仅鼠标 / 触控（免摄像头）**：直接打开 `圣诞星愿.html`。拖动旋转，点击背景或按空格切换粒子形态。
- **完整手势版（需要摄像头）**：摄像头只能在安全来源下调用，所以请通过下方任一种本地或在线方式打开。
- **网页链接**：https://nihaoxx11.github.io/christmas-wish

## 本地运行

先完整解压，保持在同一个目录里，然后任选一种：

| 系统 | 做法 |
|---|---|
| **Windows** | 双击 `启动圣诞树.bat`（需要 Python 3；未安装会自动改用免摄像头版本） |
| **macOS** | 双击 `启动圣诞树.command`（需要 Python 3） |
| **Linux / 任意系统** | 在项目根目录执行 `python3 server.py` |

脚本会启动一个**只监听本机** `http://127.0.0.1` 的网页并自动打开默认浏览器（建议 Chrome）。
关闭那个终端窗口，或在窗口里按 `Ctrl+C`，即可停止本地服务。

## 直接部署到网站

把整个仓库（含 `assets` 目录）放到任意静态托管即可。`index.html` 会自动跳转到主页
`圣诞星愿.html`，用于 GitHub Pages、Netlify 等以 `index.html` 为入口的环境。
使用 HTTPS 访问时，浏览器即可授权摄像头，手势功能与本地一致。

## 怎么玩

| 操作 | 效果 |
|---|---|
| 点击「呼神护卫」/ 按 `M` | 银蓝光环展开，守护鹿跃出、化为星尘，可重复召唤 |
| 张开手掌 / 点击「撒开星光」 | 光波与流星爆发，粒子散成三旋臂星云 |
| 握拳 / 点击「聚回圣诞树」 | 粒子聚回圣诞树 |
| 移动手掌 / 拖动背景 | 改变旋转角度 |
| 点击「挂照片」 | 选择最多 16 张本机照片，自动切到星云，建议使用 JPG / PNG / WebP |
| 拇指与食指在照片附近捏合 / 点击照片 | 放大原图，左右方向键翻看；握拳或按 `Esc` 关闭 |

照片只在当前页面会话里，刷新后需要重新选择。摄像头默认关闭；开启手势后画面在浏览器本机实时处理。
如果手部识别不稳，试着正对摄像头、露出完整手掌并改善照明。

## 特效是怎么做的

- **流畅版优化**：保留粒子数量与特效。光晕、雪花和极光使用缓存，星环刻度批量绘制；手势识别优先在后台线程处理。
- **极光魔法版**：桌面渲染约 2.46 万个 WebGL 粒子；亮金与冰蓝双螺旋绕树，树尖加强星芒，树底加动态全息星环与刻度。天空有极光、闪星和短尾流星，聚散时会出现扩散光波。
- **呼神护卫**：Canvas 手绘光鹿轮廓，用轨迹、发光粒子与逐步消散组织一段约 7 秒的召唤动画。
- **星空与降雪**：分层绘制冷暖星云、星座连线和闪烁星点；雪花由六角晶体和飘落光点组成，近处更大更快。
- **WebGL 粒子**：每颗粒子先生成两组位置——一组落在阶梯形圣诞树、螺旋灯带或装饰位置，另一组落在星云；动画用缓动插值在两组坐标之间过渡。
- **光感与景深**：用片元着色器画不同形状的光斑、星芒、彩球；通过近大远小、叠加混合、闪烁与飘雪做出空间感。
- **手势**：MediaPipe Hand Landmarker 计算一只手的 21 个关键点，再根据指尖距离与手指是否伸直判断张手、握拳、捏合；连续多帧确认后触发动画。
- **照片**：用浏览器本地对象 URL 读取照片，按同一套三维投影摆放在粒子场中，不需要上传服务器。

手势库：Google MediaPipe Tasks Vision（`0.10.22-rc.20250304`）；模型：MediaPipe Hand Landmarker（float16 v1）。

## 圣诞音效

第一次点击互动控件或按空格 / `M` 后开始循环播放 **《We Wish You a Merry Christmas》**
（传统圣诞歌曲，本项目原创音乐盒 / 竖琴纯音乐编配，单轮约 42 秒）。同一时间会播放一次圣诞铃，
以及英文祝福 **Merry Christmas!**，桌面支持播放时临时降低背景音乐音量。
左上「背景音乐」按钮可以单独暂停或继续；「圣诞音效」按钮可重播短祝福；扬声器按钮控制全部静音。
浏览器限制未交互时自动播放声音，所以首次需要点击或按键；音乐与音效均可在本地离线播放。

## 目录结构

```
圣诞星愿.html              主页面（WebGL 粒子 + 手势 + 音效）
index.html                 跳转到主页面，供静态托管作为入口
启动圣诞树.bat             Windows 一键启动（localhost + 摄像头）
启动圣诞树.command         macOS 一键启动
server.py                  本地静态服务器（补齐 MIME，仅监听 127.0.0.1）
assets/
  mediapipe/               MediaPipe 手势识别（WASM + 模型，本地离线）
  audio/                   圣诞音乐与音效
  fonts/                   Great Vibes 手写字体
使用说明.md                完整使用说明
```
